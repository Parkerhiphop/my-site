# 文章段落的固定網址

三個語言的對應標題都加上相同的固定 ID：

```md
## 來日本的理由 {#why-japan}

## Why I Came to Japan {#why-japan}

## 日本に来た理由 {#why-japan}
```

每行分別放在 `zh-TW.md`、`en.md`、`ja.md`。支援 `#` 到 `######` 的 Markdown 標題；標記放在標題末尾。網頁、目錄與 RSS 不會顯示 `{#why-japan}`，複製的段落連結則使用 `#why-japan`。

- ID 使用小寫英文字母、數字及單一連字號分隔，例如 `why-japan`。
- 同篇文章內不能重複；不同文章可以使用相同 ID。
- 修改標題、翻譯或移動段落時，保留原來的 ID。新增段落則分配新的 ID。
- 翻譯時保留 `{#...}`，只翻譯標題文字。
- 沒有註記的標題仍可顯示並自動產生 ID，但無法保證跨語言相容；檢查指令會要求補上。
- 舊標題的文字錨點保留為相容入口。從舊錨點切換語言時會改用固定 ID；未來再次更改標題不會自動保存所有歷史名稱，因此對外分享請使用固定 ID。

驗證：

```sh
pnpm test:anchors
pnpm check:anchors
```

檢查會編譯所有語言文章、拒絕不合法／重複／未指定 ID 的標題，並列出各語言缺少的對應段落。段落缺少只列警告，不會替作者補寫或重新翻譯內容。

目前三組文章的段落結構不同：

- `atomic-habits-note`：中文版經過重整，部分細節已合併或新增；已按內容配對相同主題的 ID。
- `how-to-build-a-fitness-habit`：英文版沒有「推薦資源」段落。
- `life-in-kusatsu`：日文版沒有「應對討厭的同事」段落。

這些文章只有實際存在對應 ID 的段落能跨語言精確跳轉。可用 `check:anchors` 查看完整缺少清單。
