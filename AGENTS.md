# Blog translation guidelines

When translating or editing posts in `data/stream`, `data/review`, or `data/life`:

- Treat the author's `zh-TW.md` as the source unless the user specifies another source. Do not change the Chinese original as part of a translation; suggest any source edits to the user first.
- Write for native readers rather than following Chinese wording or sentence order. English should read like natural personal blog prose, and Japanese should read like natural Japanese prose. Rephrase idioms and restructure sentences when needed, while preserving the author's meaning, voice, level of certainty, paragraph flow, quotations, and factual details. Do not add claims that are absent from the source.
- For `data/stream/**/ja.md` and `data/review/**/ja.md`, use consistent written plain form (常体). Avoid both overly casual タメ口 and stiff academic phrasing.
- For `data/life/**/ja.md`, use consistent です／ます style.

Apply these conventions to new and updated posts. An explicit instruction from the user takes precedence.
